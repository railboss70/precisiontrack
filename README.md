# PrecisionTrack

STX weekly time tracker for Matt Pitsenbarger.

## Open on your phone

1. GitHub repo: Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: **main** / **/** (root)
4. Save
5. After a minute open:
   https://railboss70.github.io/precisiontrack/
6. Safari → Share → **Add to Home Screen**

Time stays on the phone (localStorage). It does not upload punches to GitHub.

## Logo

Add `logo.jpg` (STX mark) to this repo root so the header and report show the real logo.
